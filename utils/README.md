# Utilities

General-purpose utility scripts.

## Files

### `combine_all_folders.py`

Merges two source directories of simulation output files into a single destination directory.

**Purpose:** Used specifically to consolidate two batches of Rivanna HPC kymograph outputs (`domain_0_2_from_rivanna_kymographs` and `domain_0_2_from_rivanna_kymographs/new`) that were transferred back from the cluster in separate batches.

**Behavior:**
- Copies only files with `phi` in the filename
- Detects and logs duplicate/conflicting filenames to `output.txt`
- Reports conflicts without overwriting (safe merge)

**Usage:**
```python
# Edit source and destination paths at top of script, then:
python combine_all_folders.py
```

### `output.txt`

Log file generated by `combine_all_folders.py`. Contains 210 entries of duplicate/conflict filenames encountered when merging the two Rivanna output batches. All entries are phi output file paths from Rivanna simulations.
